.. py:function:: HSI2RGB(wY, HSI, d = 65, threshold=0.002)

   Calculate a colore accurate RGB image with HSI values. Original function used for the paper
   "Creating RGB Images from Hyperspectral Images Using a Color Matching Function" by
   M. Magnusson, J. Sigurdsson, S. E. Armansson, M. O. Ulfarsson, H. Deborah and J. R. Sveinsson,

   If you use this method, please cite the following paper:
   @INPROCEEDINGS{hsi2rgb,
   author={M. {Magnusson} and J. {Sigurdsson} and S. E. {Armansson}
   and M. O. {Ulfarsson} and H. {Deborah} and J. R. {Sveinsson}},
   booktitle={IEEE International Geoscience and Remote Sensing Symposium},
   title={Creating {RGB} Images from Hyperspectral Images using a Color Matching Function},
   year={2020}, volume={}, number={}, pages={}}

   Paper is available at
   https://www.researchgate.net/profile/Jakob_Sigurdsson

   :param wY: Wavelengths in nm
   :param HSI: Hyperspectral image, a (lines, samples, bands) array
   :param d: Determines the illuminant used, if in doubt use d65. Values of  50, 55, 65, 75
   :param threshold: True if RGB thesholding should be done to increase contrast

   :return: RGB Image array


.. py:function:: adjust_exposure(image, ev = None, percentile = 99.0, target = 0.9, gamma = None, full_scale = 255.0, normalize = False, black_point=None, black_percentile = 1.0)

   Brighten or darken an RGB image with one gain for all channels.

   :param image: ``(y, x, channel)`` DataArray, a Dataset with ``R``, ``G``, ``B``
                 variables, or an array whose last axis is R, G, B.
   :type image: xarray.DataArray, xarray.Dataset or numpy.ndarray
   :param ev: Exposure change in stops (gain 2**ev): +1 doubles, -1 halves. Default:
              automatic, so the ``percentile`` of the luminance lands at ``target``
              of ``full_scale``.
   :type ev: float, optional
   :param percentile: Automatic exposure only.
   :type percentile: float, default 99 and 0.9
   :param target: Automatic exposure only.
   :type target: float, default 99 and 0.9
   :param gamma: Display gamma applied after the gain (e.g. 2.2 lifts dark water);
                 None keeps the result linear.
   :type gamma: float, optional
   :param full_scale: The value of white: 255 for the camera's 8-bit counts, 1 for 0-1
                      images such as HSI2RGB output.
   :type full_scale: float, default 255
   :param normalize: Return 0-1 values instead of 0-``full_scale``.
   :type normalize: bool, default False
   :param black_point: Subtract a black level before the gain: ``"channel"`` the
                       ``black_percentile`` of each channel (removes haze and the camera's
                       dark offset; usually the most natural look over water), ``"common"``
                       one level for all channels (keeps the colour balance), or given
                       value(s) in the image's units. None (default): gain only. A channel
                       that is saturated (e.g. blue in a bright summer capture) cannot be
                       restored, and per-channel levels then shift the colour.
   :type black_point: {None, "common", "channel"} or float or 3 floats, optional
   :param black_percentile: For ``"common"``/``"channel"``.
   :type black_percentile: float, default 1

   :returns: Float32, clipped at full scale (saturated pixels stay white). Xarray
             results carry ``exposure_gain``, ``exposure_ev``, ``exposure_gamma``
             and ``exposure_black`` attributes.
   :rtype: Same type as ``image``


.. py:function:: black_level(rgb, mode='channel', percentile = 1.0)

   Black level(s) to subtract: the ``percentile`` of each channel
   (``"channel"``: removes a colour cast such as atmospheric haze, like dark
   object subtraction) or its smallest value over the channels
   (``"common"``: keeps the colour balance).

   :type camera: xarray.DataArray

   :rtype: xarray.Dataset

.. py:function:: plot_rgb_map(source, ax=None, graticule = True, scale_bar = True, north_arrow = True, coastlines = False, title = None, stretch=(2, 98), graticule_step = None, exposure = None)

   Plot a gridded RGB image as a map.

   :param source: A gridded camera image (:func:`regrid_camera`) or a regridded product
                  (its bands nearest 640, 550 and 460 nm).
   :type source: xarray.Dataset or hypso.Product
   :param ax: Axes to draw on; default a new figure.
   :type ax: matplotlib.axes.Axes, optional
   :param graticule: Latitude/longitude lines with labels.
   :type graticule: bool, default True
   :param scale_bar: A scale bar (km) in the lower left.
   :type scale_bar: bool, default True
   :param north_arrow: An arrow to true north (in a UTM grid, true north is not straight up).
   :type north_arrow: bool, default True
   :param coastlines: Natural Earth 10 m coastlines (needs cartopy and its data; skipped
                      with a warning otherwise).
   :type coastlines: bool, default False
   :param title:
   :type title: str, optional
   :param stretch: Percentiles mapped to black and white per channel.
   :type stretch: tuple of float, default (2, 98)
   :param graticule_step: Degrees between graticule lines; default chosen from the extent.
   :type graticule_step: float, optional
   :param exposure: Use :func:`hypso.rgb.adjust_exposure` (one gain for all channels,
                    colours kept) instead of the per-channel ``stretch``, with these
                    arguments, e.g. ``{}`` (automatic), ``{"ev": 1}`` or
                    ``{"gamma": 2.2}``.
   :type exposure: dict, optional

   :rtype: matplotlib.axes.Axes

.. py:function:: register_camera(camera, hsi, resolution = 150.0, downsample = 0.25, min_inliers = 30, min_coverage = 0.25, max_rms_m = 500.0, ratio = 0.8, ransac_threshold_px = 3.0, seed = 0)

   Register a camera image to an HSI capture.

   :param camera: ``(y, x, channel)`` image from :func:`hypso.rgb.read_camera_image`
                  (demosaiced, rotated as the ground processing does).
   :type camera: xarray.DataArray
   :param hsi: The capture's L1C or L1D product (needs geolocation).
   :type hsi: hypso.Product
   :param resolution: Pixel size (m) of the UTM map the camera is matched against.
   :type resolution: float, default 150
   :param downsample: Scale of the camera image used for matching.
   :type downsample: float, default 0.25
   :param min_inliers: Quality check: at least this many RANSAC inliers, covering at least
                       this fraction of the camera image (convex hull), with at most this
                       residual RMS (m).
   :param min_coverage: Quality check: at least this many RANSAC inliers, covering at least
                        this fraction of the camera image (convex hull), with at most this
                        residual RMS (m).
   :param max_rms_m: Quality check: at least this many RANSAC inliers, covering at least
                     this fraction of the camera image (convex hull), with at most this
                     residual RMS (m).
   :param ratio: Lowe's ratio test for descriptor matching.
   :type ratio: float, default 0.8
   :param ransac_threshold_px: RANSAC inlier threshold, in map pixels.
   :type ransac_threshold_px: float, default 3
   :param seed: RANSAC random seed (reproducible results).
   :type seed: int, default 0

   :rtype: CameraRegistration


.. py:function:: regrid_camera(geo, target='utm', resolution = None, method = 'auto', max_gb = 2.0)

   A georeferenced camera image on a map grid.

   :param geo: From :func:`hypso.rgb.georeference_camera` (R, G, B, latitude, longitude).
   :type geo: xarray.Dataset
   :param target: ``"utm"`` (zone of the image centre), any CRS, or a grid - e.g. the HSI
                  product's after regridding, ``l1d.regrid(...).area_definition()``, to
                  put both on the same grid.
   :type target: str, int, pyproj.CRS or pyresample.geometry.AreaDefinition, default "utm"
   :param resolution: Pixel size in the CRS's units; default the camera's own (~30 m). Not
                      with an AreaDefinition.
   :type resolution: float, optional
   :param method: Cell means of the camera pixels in each cell, or the nearest pixel;
                  "auto" averages when cells are at least twice the camera's pixel
                  size and takes the nearest pixel otherwise (averaging onto cells as
                  small as the pixels leaves empty cells).
   :type method: {"auto", "average", "nearest"}, default "auto"
   :param max_gb: Refuse grids larger than this.
   :type max_gb: float, default 2

   :returns: ``R``, ``G``, ``B`` on ``(y, x)`` with CF projection coordinates and a
             ``crs`` grid mapping (NaN where the camera has no data), and the
             camera's attributes plus ``grid``.
   :rtype: xarray.Dataset
