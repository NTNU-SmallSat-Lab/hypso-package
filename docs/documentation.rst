Documentation
=============

This site is built with Sphinx from ``docs/``. The API reference is
generated by sphinx-autoapi from the docstrings in ``hypso/hypso``, which
are written in NumPy style.

.. code-block:: bash

   pip install -r docs/requirements.txt
   sphinx-build -W --keep-going -b html docs docs/_build/html

``-W`` turns warnings into errors, as in CI: the GitHub workflow
``.github/workflows/docs.yaml`` builds the site for every push and pull
request and publishes it from ``main`` to the ``gh-pages`` branch.
