hypso.rgb.camera#

HYPSO-2’s RGB camera: reading its images (groundwork for camera support).

A capture directory holds the camera image as <capture id>-rgb/<target>_ <YYYY_MM_DD>T<HH_MM_SS>.bmp: one 8-bit raw Bayer mosaic (3840 x 2748), taken about 2 s before the HSI capture starts. The mosaic is RGGB; the ground processing’s demosaiced copy (processing-temp/rgb-camera-image-debayered.png) is this module’s bilinear RGGB demosaic rotated 180 degrees (checked on the 2025-04-04 Ariake capture: correlation 0.98-1.00 per channel). The file has no georeferencing. Reading never registers it; that is an explicit step, hypso.rgb.register_camera() (the HSI product gives the geolocation).

Examples

>>> image = read_camera_image(find_camera_image(capture_dir))
>>> image.sel(channel="G")
