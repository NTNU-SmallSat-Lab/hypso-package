hypso.rgb.product#

RGB camera products: the camera image as a CF NetCDF file.

The camera is not a hypso.Product: that models a spectral cube with wavelengths, calibration levels and SRFs, none of which a three-channel, uncalibrated camera has. A camera product is an xarray Dataset with the same conventions:

  • R, G, B on (y, x): demosaiced counts in the camera’s own frame (not resampled), stored as uint8 (the camera’s 8 bits; the bilinear demosaic is rounded);

  • latitude, longitude per pixel and in_hsi_swath when registered (hypso.rgb.register_camera()); unregistered products have none;

  • attributes: instrument RGB, satellite, target, acquisition time, processing_level L1A (uncalibrated counts), the registration, CF/ACDD.

File names follow hypso.io.naming with the RGB instrument token: HYPSO2_RGB.<time>.<target>.L1A.nc. Satpy reads them with the hypso_rgb_l1a reader (true_color composite).

hypso.rgb.product.camera_product(camera, registration=None, hsi=None, sat_id='HYPSO-2', target=None)[source]#

A camera product from a camera image, georeferenced if registered.

Parameters:

  • camera (xarray.DataArray) – (y, x, channel) image from hypso.rgb.read_camera_image().

  • registration (hypso.rgb.CameraRegistration, optional) – From hypso.rgb.register_camera(); when ok, latitude and longitude are added. A failed registration is recorded, without geolocation.

  • hsi (hypso.Product, optional) – The capture’s HSI product: target, satellite and in_hsi_swath.

  • sat_id (str, default "HYPSO-2") – Used when no hsi is given (HYPSO-2 carries the camera).

  • target (str, optional) – Capture target; default from hsi, else from the image file name.

Return type:

xarray.Dataset
