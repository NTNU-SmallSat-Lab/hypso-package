hypso.rgb.HSI2RGB(wY, HSI, d=65, threshold=0.002)[source]#

Calculate a colore accurate RGB image with HSI values. Original function used for the paper “Creating RGB Images from Hyperspectral Images Using a Color Matching Function” by M. Magnusson, J. Sigurdsson, S. E. Armansson, M. O. Ulfarsson, H. Deborah and J. R. Sveinsson,

If you use this method, please cite the following paper: @INPROCEEDINGS{hsi2rgb, author={M. {Magnusson} and J. {Sigurdsson} and S. E. {Armansson} and M. O. {Ulfarsson} and H. {Deborah} and J. R. {Sveinsson}}, booktitle={IEEE International Geoscience and Remote Sensing Symposium}, title={Creating {RGB} Images from Hyperspectral Images using a Color Matching Function}, year={2020}, volume={}, number={}, pages={}}

Paper is available at https://www.researchgate.net/profile/Jakob_Sigurdsson

Parameters:

  • wY – Wavelengths in nm

  • HSI – Hyperspectral image, a (lines, samples, bands) array

  • d (Literal[50, 55, 65, 75]) – Determines the illuminant used, if in doubt use d65. Values of 50, 55, 65, 75

  • threshold – True if RGB thesholding should be done to increase contrast

Returns:

RGB Image array

Return type:

hypso.rgb.adjust_exposure(image, ev=None, percentile=99.0, target=0.9, gamma=None, full_scale=255.0, normalize=False, black_point=None, black_percentile=1.0)[source]#

Brighten or darken an RGB image with one gain for all channels.

Parameters:

  • image (xarray.DataArray, xarray.Dataset or numpy.ndarray) – (y, x, channel) DataArray, a Dataset with R, G, B variables, or an array whose last axis is R, G, B.

  • ev (float, optional) – Exposure change in stops (gain 2**ev): +1 doubles, -1 halves. Default: automatic, so the percentile of the luminance lands at target of full_scale.

  • percentile (float, default 99 and 0.9) – Automatic exposure only.

  • target (float, default 99 and 0.9) – Automatic exposure only.

  • gamma (float, optional) – Display gamma applied after the gain (e.g. 2.2 lifts dark water); None keeps the result linear.

  • full_scale (float, default 255) – The value of white: 255 for the camera’s 8-bit counts, 1 for 0-1 images such as HSI2RGB output.

  • normalize (bool, default False) – Return 0-1 values instead of 0-full_scale.

  • black_point ({None, "common", "channel"} or float or 3 floats, optional) – Subtract a black level before the gain: "channel" the black_percentile of each channel (removes haze and the camera’s dark offset; usually the most natural look over water), "common" one level for all channels (keeps the colour balance), or given value(s) in the image’s units. None (default): gain only. A channel that is saturated (e.g. blue in a bright summer capture) cannot be restored, and per-channel levels then shift the colour.

  • black_percentile (float, default 1) – For "common"/"channel".

Returns:

Float32, clipped at full scale (saturated pixels stay white). Xarray results carry exposure_gain, exposure_ev, exposure_gamma and exposure_black attributes.

Return type:

Same type as image

  • graticule_step (float, optional) – Degrees between graticule lines; default chosen from the extent.

  • exposure (dict, optional) – Use hypso.rgb.adjust_exposure() (one gain for all channels, colours kept) instead of the per-channel stretch, with these arguments, e.g. {} (automatic), {"ev": 1} or {"gamma": 2.2}.

hypso.rgb.register_camera(camera, hsi, resolution=150.0, downsample=0.25, min_inliers=30, min_coverage=0.25, max_rms_m=500.0, ratio=0.8, ransac_threshold_px=3.0, seed=0)[source]#

Register a camera image to an HSI capture.

Parameters:

  • camera (xarray.DataArray) – (y, x, channel) image from hypso.rgb.read_camera_image() (demosaiced, rotated as the ground processing does).

  • hsi (hypso.Product) – The capture’s L1C or L1D product (needs geolocation).

  • resolution (float, default 150) – Pixel size (m) of the UTM map the camera is matched against.

  • downsample (float, default 0.25) – Scale of the camera image used for matching.

  • min_inliers (int) – Quality check: at least this many RANSAC inliers, covering at least this fraction of the camera image (convex hull), with at most this residual RMS (m).

  • min_coverage (float) – Quality check: at least this many RANSAC inliers, covering at least this fraction of the camera image (convex hull), with at most this residual RMS (m).

  • max_rms_m (float) – Quality check: at least this many RANSAC inliers, covering at least this fraction of the camera image (convex hull), with at most this residual RMS (m).

  • ratio (float, default 0.8) – Lowe’s ratio test for descriptor matching.

  • ransac_threshold_px (float, default 3) – RANSAC inlier threshold, in map pixels.

  • seed (int, default 0) – RANSAC random seed (reproducible results).

hypso.rgb.regrid_camera(geo, target='utm', resolution=None, method='auto', max_gb=2.0)[source]#

A georeferenced camera image on a map grid.

Parameters:

  • geo (xarray.Dataset) – From hypso.rgb.georeference_camera() (R, G, B, latitude, longitude).

  • target (str, int, pyproj.CRS or pyresample.geometry.AreaDefinition, default "utm") – "utm" (zone of the image centre), any CRS, or a grid - e.g. the HSI product’s after regridding, l1d.regrid(...).area_definition(), to put both on the same grid.

  • resolution (float, optional) – Pixel size in the CRS’s units; default the camera’s own (~30 m). Not with an AreaDefinition.

  • method ({"auto", "average", "nearest"}, default "auto") – Cell means of the camera pixels in each cell, or the nearest pixel; “auto” averages when cells are at least twice the camera’s pixel size and takes the nearest pixel otherwise (averaging onto cells as small as the pixels leaves empty cells).

  • max_gb (float, default 2) – Refuse grids larger than this.

Returns:

R, G, B on (y, x) with CF projection coordinates and a crs grid mapping (NaN where the camera has no data), and the camera’s attributes plus grid.

Return type:

xarray.Dataset
