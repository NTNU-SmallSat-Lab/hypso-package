class hypso.grid.Averager(latitudes, longitudes, target)[source]#

Cell averages on a grid: each target cell gets the mean of the source pixels whose centres fall in it (NaN ignored per band) - an unweighted approximation of area-weighted averaging, close when source pixels are much smaller than the cells. Only for targets coarser than the source; finer ones leave empty cells inside the swath.

class hypso.grid.GridOperators(tree, target, method, radius_of_influence=None)[source]#

How each kind of variable goes from a product onto target with method, so resample_product and regrid treat variables alike:

  • floats(): the cube and float variables - nearest, bilinear, or cell average; azimuths (by name) through their sine and cosine unless nearest, so 0/360 does not average to 180;

  • integers(): nearest neighbour, except bit flags with “average”, which are OR-ed over the cell;

  • covered(): target pixels that received data.

Parameters:

hypso.grid.regrid(tree, target='utm', resolution=None, method='nearest', radius_of_influence=None, max_gb=4.0)[source]#

A product tree on a map grid, at the same level.

Parameters:

  • tree (xarray.DataTree) – L1C, L1D or L2A product tree.

  • target (str, int, pyproj.CRS or pyresample.geometry.AreaDefinition, default "utm") – "utm" (WGS84 UTM zone of the scene centre), a CRS pyproj accepts (e.g. "EPSG:3035", 4326), or an AreaDefinition (e.g. another product’s grid).

  • resolution (float, optional) – Pixel size in the CRS’s units (m, or degrees for a geographic CRS); default the product’s resolution. Not with an AreaDefinition.

  • method ({"nearest", "bilinear", "average"}, default "nearest") – See the module description.

  • radius_of_influence (float, optional) – In m; default 1.5 times the coarser of source and target pixel size.

  • max_gb (float, default 4.0) – Refuse grids whose cube would exceed this many GB (a fine grid over a long capture gets large quickly).

Return type:

xarray.DataTree
