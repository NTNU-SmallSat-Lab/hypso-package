calibrate(coeff_type=None, version=None, **kwargs)[source]#

Calibrate L1A to L1B: top-of-atmosphere radiance Lt.

Parameters:

  • coeff_type (str, optional) – Radiometric variant: "abs" (default), "moved" or "lab".

  • version (str or dict, optional) – Coefficient release: "V3.1" (default), "V3.1v2spec" (for OC-SMART), "V2", "V1"; or {correction: release} to mix them, e.g. {"smile": "V2"}. See docs/calibration.rst.

  • **kwargs – Passed to hypso.processing.l1a_to_l1b(): coeff_files (explicit files), radiometric, smile, destripe, spectral (False to skip a correction), and keystone (True to apply the sensor’s keystone model; unreviewed groundwork).

Returns:

L1B; the coefficients used and their checksums are recorded in provenance.

Return type:

Product

Atmospheric correction to L2A.

An L2B product from one of the package’s algorithms (from L2A).

regrid(target='utm', resolution=None, method='nearest', radius_of_influence=None, max_gb=4.0)[source]#

The product on a map grid, at the same level.

Parameters:

  • target (str, int, pyproj.CRS, AreaDefinition or Product, default "utm") – "utm" (the WGS84 UTM zone of the scene centre), any CRS pyproj accepts (e.g. "EPSG:3035"), a pyresample AreaDefinition, or a gridded Product to share its grid.

  • resolution (float, optional) – Pixel size in the CRS’s units. Default: this product’s resolution, so nothing is oversampled. Not with an AreaDefinition or Product target.

  • method ({"nearest", "bilinear", "average"}, default "nearest") – "nearest" keeps one measured spectrum per pixel; "bilinear" blends neighbouring spectra; "average" takes cell means, for grids at least as coarse as the product.

  • radius_of_influence (float, optional) – Search radius in m; default 1.5 times the coarser pixel size.

  • max_gb (float, default 4.0) – Refuse grids whose cube would be larger.

Returns:

Dimensions (y, x) with CF projection coordinates and a crs grid mapping; pixel_flags gains outside_swath.

Return type:

Product

to(level, calibrate=None, georeference=None, toa_reflectance=None, correct_atmosphere=None)[source]#

Run the processing steps from this level up to level.

Parameters:

  • level ({"L1B", "L1C", "L1D", "L2A"}) – Target level.

  • georeference (dict, optional) – Options for each step, passed to the method of that name. For L2A, correct_atmosphere={"method": ...} picks the method (default MACHI).

  • toa_reflectance (dict, optional) – Options for each step, passed to the method of that name. For L2A, correct_atmosphere={"method": ...} picks the method (default MACHI).

  • correct_atmosphere (dict, optional) – Options for each step, passed to the method of that name. For L2A, correct_atmosphere={"method": ...} picks the method (default MACHI).

Return type:

Product

Examples

>>> l1d = l1a.to("L1D", calibrate={"version": "V2"},
...              georeference={"latitudes": lats, "longitudes": lons})
>>> l2a = l1d.to("L2A")                                        # MACHI
>>> l2a = l1d.to("L2A", correct_atmosphere={"method": "dps"})

write(path=None, out_dir=None, label=None, datacube=False, significant_bits=14, tool_products=True, intermediates=True)[source]#

Write the product in the current file format.

Parameters:

  • path (str or path, optional) – Output file. Default: filename() in out_dir.

  • out_dir (str or path, optional) – Directory for the default name; the current directory if omitted.

  • label (str, optional) – Label for the default name.

  • datacube (bool, default False) – Write the cube as one 3D variable instead of one per band.

  • significant_bits (int or None, default 14) – Keep this many significant mantissa bits of the float bands (L1B-L2A): about 40% smaller L1D bands at most 3.1e-5 relative error; None writes them lossless.

  • tool_products (bool, default True) – L2A: also write the AC tool’s own products (tool_products()) as L2B files in the same directory. The L2A file never holds them; False drops them (with a warning).

  • intermediates (bool, default True) – L2A: also write the AC tool’s other per-band outputs (intermediates(), e.g. OC-SMART’s Lt, Lr, Lrc, tg_sol) as the ...L2A.AUX.<method>.nc file in the same directory. False drops them (with a warning).

Returns:

The written file (for L2A, the L2A file).

Return type:

pathlib.Path

Read any supported HYPSO product file into the in-memory model.

Parameters:

  • path (str or pathlib.Path)

  • wavelength_range (optional) – Read only some bands, selected as in hypso.processing.bands.select_bands() (at most one of them). Only the selected band variables are read from the file; a file holding the cube as one variable is read whole and then subset.

  • wavelengths (optional) – Read only some bands, selected as in hypso.processing.bands.select_bands() (at most one of them). Only the selected band variables are read from the file; a file holding the cube as one variable is read whole and then subset.

  • indices (optional) – Read only some bands, selected as in hypso.processing.bands.select_bands() (at most one of them). Only the selected band variables are read from the file; a file holding the cube as one variable is read whole and then subset.

xarray.DataTree

hypso.write_product(tree, path, datacube=False, significant_bits=SIGNIFICANT_BITS)[source]#

Write a product tree in the current file format.

Parameters:

  • tree (xarray.DataTree) – In-memory model (see the module description).

  • path (str or pathlib.Path)

  • datacube (bool, default False) – Write the cube as one 3D variable instead of one variable per band.

  • significant_bits (int or None, default 14) – Keep this many significant mantissa bits of the float band variables (L1B-L2A; netCDF BitRound, max relative error 2**-(bits + 1); values stay float32, NaN is kept, readers need nothing special). None writes them lossless. L1A counts, geometry, derived variables and metadata are always lossless. Recorded in the band_quantization global attribute.

None
