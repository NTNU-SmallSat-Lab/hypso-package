hypso.io.provenance#

Processing provenance carried in every product.

Each processing step adds a metadata/processing/<step> node (one per step, kept when the product is read and written again, so a file holds its whole lineage) and one line to the global history attribute:

2026-10-26T10:02:11Z: l1d from HYPSO2_HSI.20250612T095802.aeronetvenice.L1C.nc,

hypso-package 26.10.0 (git 25f4c3bf)

Node attributes: date_utc, software / software_version / software_git_commit / software_git_dirty, input_file, the step’s parameters (scalars as attributes, anything else as JSON), and optionally:

  • calibration: package / version / git commit, and <kind>_file + <kind>_sha256 for every coefficient file loaded (versions alone don’t identify coefficients - see docs/versioning.rst);

  • ac: tool, version, git commit, install path, settings_effective (full settings actually used, JSON) and settings_user (only what the user set). Credential-like keys are removed and listed in settings_redacted_keys.
