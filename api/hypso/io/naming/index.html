hypso.io.naming#

Product file names.

Current style, NASA OB.DAAC-like - satellite and instrument first, then time, so a plain listing groups by satellite and sorts by time:

{SAT}_{INSTRUMENT}.{YYYYMMDDTHHMMSS}.{target}.{LEVEL}[.{QUANTITY|GROUP}.{source}][.{grid}][.{label}].nc

HYPSO2_HSI.20250612T095802.aeronetvenice.L1A.nc
HYPSO2_HSI.20250612T095802.aeronetvenice.L1D.nc
HYPSO2_HSI.20250612T095802.aeronetvenice.L2A.RRS.polymer.nc
HYPSO2_HSI.20250612T095802.aeronetvenice.L2A.RHOS.machi.nc
HYPSO2_HSI.20250612T095802.aeronetvenice.L2B.BGC.oc4.nc
HYPSO2_HSI.20250612T095802.aeronetvenice.L1D.adjusted.nc   (label: experiments)
HYPSO2_HSI.20250612T095802.aeronetvenice.L2A.RRS.polymer.utm33n_880m.nc   (regridded)

The first field is the satellite and the instrument, like NASA’s {MISSION}_{INSTRUMENT} (PACE_OCI): HYPSO2_HSI is HYPSO-2’s Hyperspectral Imager, the instrument every product so far comes from (INSTRUMENTS lists the known ones). . separates fields and never appears inside one. L2A always carries the quantity (QUANTITIES: RRS remote-sensing reflectance, RHOS surface reflectance; AUX the AC tool’s other per-band outputs, AUX_QUANTITY) and the AC method, which produced it; L2B (products derived from an L2A) always carries its product group (L2B_GROUPS, e.g. BGC) and the source (the algorithm or AC tool) in the same two fields; a regridded product carries its grid (hypso.grid.grid_name: utm<zone><n|s> or epsg<code>, then the pixel size, e.g. utm33n_880m, epsg4326_0p01deg); the optional free-text label is always last and may not look like a grid. Calibration set and masking state are not part of the name - they are recorded in the file. Times are UTC.

Legacy names ({target}_{YYYY-MM-DDTHH-MM-SSZ}[-{label}]-{level}[-{ac}].nc, where label mixed calibration set and masking, e.g. “moved_unmasked”) are still parsed, so existing datasets stay readable. Capture directories keep the capture ID form {target}_{YYYY-MM-DDTHH-MM-SSZ}.

hypso.io.naming.product_name(sat_id, time, target, level, ac=None, label=None, grid=None, instrument='HSI', quantity=None)[source]#

Compose a product name.

Parameters:

  • sat_id (str) – e.g. "HYPSO-2".

  • time (datetime.datetime) – Capture start; converted to UTC if timezone-aware.

  • target (str) – Capture target, e.g. "aeronetvenice".

  • level (str) – "L1A" … "L1D", "L2A".

  • ac (str, optional) – Atmospheric correction method (L2A) or source (L2B: algorithm or tool); required there, not allowed otherwise.

  • label (str, optional) – Free-text label for experiments (letters, digits, _, -).

  • grid (str, optional) – Grid name of a regridded product (hypso.grid.grid_name()).

  • instrument (str, default "HSI") – Instrument token (INSTRUMENTS).

  • quantity (str, optional) – L2A quantity token (QUANTITIES, e.g. "RRS", or the product variable "Rrs") or L2B group (L2B_GROUPS, e.g. "BGC"); required for L2A and L2B.

Returns:

product_name(...).filename() gives the file name.

ProductName
