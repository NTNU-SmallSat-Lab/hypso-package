hypso.processing.capture.spatial_subsampling(attrs, samples=None)[source]#

(sample_div, detector_rows): the capture’s spatial subsampling and the number of detector rows its AOI spans.

Readout keeps every sample_div-th detector row along the slit, so a 1092-row AOI with subsampling 2 gives 546 samples; sample i is detector row aoi_y + i * sample_div. The factor is capture_config’s spatial_subsampling, else the older sample_div (1 in every file so far; a different value next to spatial_subsampling is warned about).

samples, the cube’s size along the slit, decides what row_count counts: the AOI’s detector rows (1092 -> 546 samples) or the rows read out (546 samples, spanning 1092 detector rows). If the config gives no subsampling (or 1) but the cube is an exact fraction of row_count, that fraction is used, with a warning. Any other mismatch is an error.

Parameters:

  • attrs (dict)

  • samples (int)

Return type:

tuple
